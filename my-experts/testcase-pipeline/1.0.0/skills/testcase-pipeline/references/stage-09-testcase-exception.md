## 🚨 最高优先级约束

**本 Skill 负责生成 YC（异常操作）与 FCG（玩家非常规操作）两类用例。**

- ✅ 允许的分类：YC、FCG
- ❌ 禁止的分类：HX、FHX、ZD、BJ、BL（这些由其他 Skill 负责）
- 🔢 **输出顺序：YC 在前，FCG 在后**（同一测试点内相邻）

---

## ⚠️ 最重要的一件事：YC / FCG 的分界

**判错即为口径混用。** 两者都是「玩家侧非正常路径」，但**病灶不同**：

| 维度 | **FCG**（玩家非常规操作） | YC（异常操作） |
|---|---|---|
| 操作权限 | **合法** —— 该玩家有此权限，按钮可点 | 不合法 —— 无权限 / 当前状态不允许 |
| 触发源 | 玩家自己（**时序 / 频次 / 入口路径**） | 玩家自己（非法输入 / 错误状态） |
| 一句话 | **动作做对了，做法不对** | **动作本身不该发出** |
| 结果要求 | 有确定处理（拦截 / 忽略 / 只生效一次） | 有确定的错误处理或容错 |

**FCG 四子类**：

| 子类 | 判据 |
|---|---|
| **连点** | 同一可点元素在短时间内被点击 ≥2 次 |
| **反复** | 同一状态被反复进入/退出，或同一动作被反复执行（含快速交替） |
| **未就绪** | 前置动画 / 加载 / 结算未播完，即发出下一步操作 |
| **乱序** | 不按设计顺序跳步操作；多入口并发进入同一流程 |

**易错点**：
- 断网时点击 → **YC**；点太快连点两次 → **FCG**
- 输入非法字符提交 → **YC**；同一提交按钮快速点 5 次 → **FCG**
- 动画没播完就点下一步 → **FCG**（不是 ZD，ZD 是动作**发出后**被切断）
- 「非首次操作」（第二次种植、第二次赠礼，有资源/状态差异）→ **HX / FHX**，不是 FCG

---

## ⚠️ 重要区分：YC / FCG / ZD

| 场景 | 分类 | 说明 |
|------|------|------|
| 断网状态下点击按钮 | **YC** | 操作前已断网，属于异常状态下的操作 |
| 操作过程中网络断开再恢复 | **ZD** | 操作中途被中断，然后恢复 |
| 弱网环境下操作 | **YC** | 网络不稳定，但未完全断开 |
| 快速连续点击 | **FCG** | 操作合法，但执行方式不正常 |
| 反复进出同一界面 | **FCG** | 状态反复进出，非异常状态 |
| 动画/加载未播完即点下一步 | **FCG** | 前置条件未就绪 |

## 核心原则：一个测试点展开为多条用例

YC 与 FCG 都按此展开，**YC 先出、FCG 后出**：

```
示例：测试点「验证创建房间异常处理」→ 展开为多条用例：
├─ YC-用例1：断网时创建房间
├─ YC-用例2：弱网时创建房间
├─ YC-用例3：服务繁忙时创建房间
├─ FCG-用例4：快速连续点击创建按钮
└─ FCG-用例5：动画未播完就点创建
```

## 执行流程

### 步骤1：读取测试点五列表格（强制）

从测试点列表的「适用分类」列筛选**含 YC 或 FCG** 的测试点，**这些测试点必须生成对应用例**。同时读取「展开说明」列获取展开线索。

**🚨 降级展开逻辑（当展开说明缺失或笼统时）**：

如果某测试点的「展开说明」中 YC / FCG 部分为空或过于笼统（如仅写"YC:异常"），则根据测试点描述按以下通用模板自行识别展开方向：

```
YC 通用降级展开模板：
├── 涉及网络请求 → 断网状态操作/弱网环境/请求超时
├── 涉及用户输入 → 非法字符/注入攻击/格式错误
├── 涉及共享资源 → 资源不存在/资源已满/资源已删除
├── 涉及权限操作 → 无权限操作/权限过期/越权访问
└── 涉及并发场景 → 操作时数据已变更/竞态条件

FCG 通用降级展开模板：
├── 涉及可点击元素（按钮/icon/页签/列表项） → 连点
├── 涉及前置动画/加载/结算/二次确认 → 未就绪
├── 涉及可反复进入退出的状态（面板/界面/场景） → 反复
└── 存在多入口或需按顺序多步操作 → 乱序
```

**覆盖率检查**（生成完用例后执行）：
```
□ 逐个检查适用分类包含 YC 的测试点，每个至少 1 条 YC 用例（数量标准见 `_shared_conventions.md §11.1`）
□ 逐个检查适用分类包含 FCG 的测试点，每个至少 1 条 FCG 用例（同上，§11.1）
□ 未覆盖的测试点需补充用例或说明原因
```

### 步骤2：识别场景类型

```
【YC】
□ 网络异常 → 断网状态操作、弱网环境、网络延迟、请求超时
□ 非法输入 → 非法字符、注入攻击、格式错误、特殊符号
□ 状态异常 → 数据过期、状态失效、资源不存在、已删除、满载/上限状态
□ 权限异常 → 无权限操作、越权访问、权限过期
□ 竞态条件 → 操作时数据已变更、加入时房间满人
□ 服务端异常 → 服务繁忙、返回错误码、数据格式错误

【FCG】
□ 连点 → 可点击元素的快速重复点击
□ 反复 → 状态反复进出、动作反复执行、两个互斥操作的快速交替
□ 未就绪 → 动画/加载/结算未播完即发出下一步
□ 乱序 → 跳步操作、多入口并发进入同一流程
```

## 用例模板

**YC·网络异常：**

| 异常类型 | 示例 |
|----------|------|
| 断网操作 | 断网时点击创建房间 |
| 弱网环境 | 弱网环境下加载列表 |
| 请求超时 | 加入房间超时 |
| 网络延迟 | 网络延迟时提交表单 |

> 注意区分：`断网前操作（YC）` vs `操作过程中断网再恢复（ZD）`

**YC·重复/并发异常：**

| 异常类型 | 示例 |
|----------|------|
| 重复提交 | 重复点击提交按钮（提交后按钮未置灰的竞态） |
| 并发冲突 | 加入房间时房间恰好满人 |
| 状态过期 | 加入已解散的房间 |

> ⚠️ 「快速连续点击」**不属于 YC**，归 **FCG·连点**。

**FCG·非常规交互：**

| 子类 | 示例 |
|----------|------|
| 连点 | 快速连续点击创建房间按钮 5 次 → 只创建 1 个房间 |
| 反复 | 反复开关筛选面板 → 条件不残留 |
| 未就绪 | 入场动画未播完即点【确认】→ 不重复提交 |
| 乱序 | 不按顺序跳到第 3 步操作 → 有拦截或按序兜底 |

**YC·竞态条件：**

| 异常类型 | 示例 |
|----------|------|
| 数据已变更 | 加入房间时房主修改了密码 |
| 资源已满 | 加入房间时房间恰好满人 |
| 资源已删除 | 加入房间时房间已解散 |
| 状态已变更 | 踢人时该玩家已退出 |

**YC·服务端异常：**

| 异常类型 | 示例 |
|----------|------|
| 服务繁忙 | 服务繁忙时创建房间 |
| 返回错误码 | 服务端返回500错误 |
| 数据格式错误 | 服务端返回空数据 |

**YC·非法输入：**

| 异常类型 | 示例 |
|----------|------|
| 非法字符 | 输入SQL注入字符 |
| 格式错误 | 邮箱格式错误 |
| 特殊符号 | 输入`<script>`标签 |

**YC·权限异常：**

| 异常类型 | 示例 |
|----------|------|
| 无权限 | 非房主尝试踢人 |
| 权限过期 | 登录过期后操作 |
| 越权访问 | 访问他人私密房间 |

## 场景组合设计方法

**场景组合矩阵 = 玩家状态维度 × 操作对象状态维度**

```
              │ 正常 │ 已满 │ 已解散 │ 密码变更 │ 断网 │
─────────────┼──────┼──────┼────────┼──────────┼──────┤
首次加入      │  HX  │  YC  │   YC   │    YC    │  YC  │
再次加入同房间│  YC  │  YC  │   YC   │    YC    │  YC  │
```

> 矩阵用于 YC。FCG 不按"对象状态"组合，按**执行方式**（连点/反复/未就绪/乱序）在**每个含可点击元素或前置动画的测试点**上展开。

```
□ 涉及网络请求的功能都有：断网、超时用例
□ 可点击元素都有：FCG·连点用例
```

## JSONL 输出格式（append 模式）

将生成的每条用例逐行 append 到 `测试用例_模块/{模块名}.jsonl`（UTF-8 无 BOM）：

```python
import json
from pathlib import Path

out_file = Path(archive_dir) / "测试用例_模块" / f"{module_name}.jsonl"
out_file.parent.mkdir(parents=True, exist_ok=True)
with open(out_file, "a", encoding="utf-8") as f:      # 硬约束：mode='a'
    for case in cases:
        f.write(json.dumps(case, ensure_ascii=False) + "\n")
```

**JSONL 示例**：
```jsonl
{"submodule":"创建房间","feature_point":"玩家在游戏主页面创建新房间，支持公开/密码两种模式","testpoint":"验证创建房间功能","case_desc":"断网状态下点击创建按钮","precondition":"网络已断开","steps":"1.输入房间名\n2.点击创建按钮","expected":"1.显示网络异常提示\n2.创建失败可重试","category":"YC"}
{"submodule":"创建房间","feature_point":"玩家在游戏主页面创建新房间，支持公开/密码两种模式","testpoint":"验证创建房间功能","case_desc":"弱网状态下提交创建","precondition":"网络延迟>3秒","steps":"1.输入房间名\n2.点击创建按钮","expected":"1.显示加载中\n2.超时后给出重试选项","category":"YC"}
{"submodule":"创建房间","feature_point":"玩家在游戏主页面创建新房间，支持公开/密码两种模式","testpoint":"验证创建房间功能","case_desc":"快速连点创建按钮5次","precondition":"网络正常，已输入合法房间名","steps":"1.连续点击【创建】5次","expected":"1.只创建 1 个房间\n2.不出现重复房间或重复弹窗","category":"FCG"}
```

**字段规范**：
- **必填字段**：`submodule / feature_point / testpoint / case_desc / precondition / steps / expected / category`
- **`category` 只能填 `YC` 或 `FCG`**（本 skill 负责的分类）
- **`module` 可省略**：由渲染层用文件名兜底
- **`feature_point` 必填**：值 = 测试点表格**第 2 列**「功能点描述」；**禁止留空、禁止依赖渲染层反查**
- **`testpoint` 与拆分器输出保持一致**：不重命名、不重排
- **多步骤用 `\n` 换行**（禁 `<br>`）
- 详细规范参见 `_shared_conventions.md §8.3`

## 注意事项

1. **只生成 YC 和 FCG 分类的用例**
2. **必须使用 `open(mode='a')` 追加 JSONL**，禁止 `write_to_file` 覆盖已有文件；禁止 `replace_in_file` 修改 JSONL
3. 保持模块和子模块命名一致性
4. 三个"非正常"分类的分工：**YC = 动作不该发出｜FCG = 做法不对｜ZD = 发出后被切断**
